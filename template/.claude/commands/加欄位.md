# /加欄位

1. **印出 ALTER TABLE 給使用者執行**，不要自己用 service_role key 改：
   ```sql
   alter table public.<表名> add column if not exists <欄位名> <型別>;
   ```
   等使用者回報已執行成功，再進行下一步。
2. **改前端，以下五個地方都要改到**：
   - **表單**：`js/core.js` 對應模組的 `M.<模組>.fields` 陣列加入這個欄位
     的定義（型別、標籤、是否必填、是否要格式化成金額等）
   - **清單**：確認 `M.<模組>.cols` 有沒有要把新欄位加進清單顯示；如果
     欄位屬於分類/狀態類，考慮加進 `cellHTML()` 的 tag 判斷
   - **CSV 匯出**：`exportCSV()` 是通用邏輯，只要欄位在 `fields` 裡就會
     自動匯出，確認欄位標籤（`l`）清楚即可，不用另外改程式
   - **匯入對應**：如果這個模組在 `IMPORTABLE`（見 `js/importer.js`）
     清單裡，確認新欄位在匯入頁的欄位對應下拉選單有正確出現（同樣是
     讀 `fields`，通常不用改程式，但要實際跑一次匯入頁確認）
   - **資料字典**：`docs/schema.md` 補上這個新欄位的型別/意思/誰會填/
     可否為空
3. **驗證**：實際新增一筆、編輯一筆、匯出一次 CSV，確認新欄位正常運作。
4. **commit、push、回報**。

## 禁止事項
- 不要漏掉上面五個地方的任何一個。
- 不要自己執行 ALTER TABLE（一定要使用者手動跑，見 CLAUDE.md 通知規則）。
