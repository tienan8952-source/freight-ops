# /備份

1. 用 service_role key（本機 `.env`）對每張業務表呼叫 Supabase REST API
   `GET /rest/v1/<table>?select=*`（把 `<table>` 換成你專案 `TABLES`
   陣列裡的每一張表）
2. 組成單一 JSON：`{ "exported_at": "<ISO 時間>", "tables": { ...每張表的陣列... } }`
3. 存到 repo 根目錄的 `backups/` 資料夾，並確認 `.gitignore` 有排除
   `backups/`（備份檔含業務資料，不應該進 git）
4. 檔名格式：`<專案名>_備份_YYYY-MM-DD.json`
5. 回報備份檔案位置與各表筆數摘要。

## 禁止事項
- 備份檔不可以 commit 進 git。
- 不要用備份取代系統內建的「還原」邏輯（如果有的話，還原應該只補不刪）。
