# /部署

1. `git status` 確認要提交的內容正確（沒有不該進 git 的檔案，例如 `.env`）。
2. `git add` 相關檔案、`git commit`（訊息說明這次改了什麼）。
3. `git push`。
4. 確認線上網址正常：
   ```bash
   curl -sI https://<你的帳號>.github.io/<你的repo>/ | head -1
   ```
   要看到 `HTTP/2 200`。
5. 回報：這次 push 的 commit hash、確認結果（HTTP 200）、網址。

## 禁止事項
- 沒有先看過 `git status`／`git diff` 就直接 commit。
- push 完不做 HTTP 200 確認就回報「部署完成」。
