# /健康檢查

1. **Supabase 連線**：呼叫任一張表 `GET .../rest/v1/<table>?select=id&limit=1`
   （用 anon key），確認回應正常。
2. **各表筆數**：對每張業務表查一次筆數。
3. **Storage 用量**：Supabase 後台 Storage 頁面查看用量。
4. **最後備份時間**：檢查有沒有記錄上次備份時間的機制，超過 7 天沒
   備份要標記提醒。
5. **未處理的通知**（如果有做 agent_alerts 之類的機制）：查有沒有還沒
   處理的 action 等級項目。
6. **未提交的 git 變更**：`git status`。
7. 整理成一份簡短摘要回報，異常項目要特別標出來。

## 禁止事項
- 發現異常不要自己動手修，只回報現況，處理交給使用者決定。
