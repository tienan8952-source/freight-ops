# /備份

系統內「系統維護」頁已經有「立即備份（JSON）」按鈕（`doBackupJSON()`，
見 `js/maint.js`），這是給使用者在瀏覽器點的功能。這個指令是給 Claude
Code 從程式碼層面做等效備份時參考的流程：

1. 用 service_role key（本機 `.env`）對以下每張表呼叫 Supabase REST API
   `GET /rest/v1/<table>?select=*`：
   `vehicles`、`drivers`、`customers`、`trips`、`maint`、`petty`、
   `billing`、`insurance`、`docs`、`departments`、`workflows`、`tasks`、
   `task_events`、`uploads`
2. 組成單一 JSON：`{ "exported_at": "<ISO 時間>", "tables": { ...每張表的陣列... } }`
3. 存到 repo 根目錄的 `backups/` 資料夾（**注意：`backups/` 需要加進
   `.gitignore`，備份檔含業務資料，不應該進 git**），檔名格式：
   `貨運行營運系統_備份_YYYY-MM-DD.json`
4. 回報備份檔案位置與各表筆數摘要。

## 禁止事項
- 備份檔不可以 commit 進 git（含客戶資料等業務機密）。
- 不要用備份取代「還原」功能的還原邏輯——還原一律走系統內「系統維護」
  頁的還原功能（只補不刪，見 `docs/incident.md`「資料被誤刪」）。
