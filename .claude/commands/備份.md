# /備份

執行 `.\scripts\backup.ps1`（TP-07 建立）：用 service_role key 把每張表
匯出成 `backups/YYYY-MM-DD/<table>.json`，同時產生 `manifest.json`（各表
筆數、Storage 檔案數、匯出時間、schema 版本），並自動只保留最近 12 份。

系統內「系統維護」頁也有「下載完整備份（JSON + CSV）」按鈕
（`doFullBackupZip()`，見 `js/maint.js`），是給使用者在瀏覽器點的等效
功能，兩者互不影響、可以都用。

需要連 Storage 裡的檔案一起備份時，另外執行 `.\scripts\backup-storage.ps1`
（下載到 `backups/storage/`，可中斷續跑）。

執行完回報：備份資料夾位置、各表筆數摘要（有沒有表匯出失敗）、
Storage 檔案數。

## 禁止事項
- `backups/` 底下的東西不可以 commit 進 git（已經在 `.gitignore`，含
  客戶資料等業務機密，確認一下沒有不小心被加進 git 就好）。
- 不要用這支腳本的備份去覆蓋現有資料——還原一律走
  `scripts/restore-table.ps1`（只補不刪，見 `docs/recovery.md`「情境三：
  資料被誤刪」）或系統內「系統維護」頁的還原功能。
