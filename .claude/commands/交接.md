# /交接

產生一份簡短、誠實的狀態摘要，供接手的人（可能是使用者自己過一陣子回來，
也可能是另一個 Claude Code 對話）快速掌握現況：

1. **做到哪**：`git log --oneline -15` 摘要最近做了什麼；`git status`
   確認有沒有還沒 commit 的變更。
2. **卡在哪**：有沒有等待使用者手動處理的事（例如某個 SQL 還沒執行、
   某個金鑰還沒填、`docs/incident.md` 裡是否有正在處理中的事故）；查
   `agent_alerts` 表有沒有還沒 `resolved_at` 的 `level=action` 項目。
3. **下一步**：如果有明確的下一步（例如任務包還有沒做完的階段），列出
   來；如果沒有明確下一步，寫「目前沒有已知待辦」，不要編造。
4. 摘要控制在能讓人一分鐘看完的長度，不要把整個對話紀錄複製貼上。

## 禁止事項
- 不要為了讓摘要看起來完整而編造「已完成」或「下一步」，不確定的事情
  要照實寫「不確定」或「未驗證」（跟 `docs/prompts.md` 裡「怎麼要求它
  誠實回報」那條原則一致）。
