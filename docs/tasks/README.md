# 任務包存放規則

- 任務包統一存在 `docs/tasks/` 這個資料夾，檔名格式：`TP-XX-簡短名稱.md`（`XX` 為兩位數流水號，例如 `TP-04`、`TP-09`）。
- 每份任務包開頭要有「目錄」，列出各階段對應的標題，方便直接跳讀，不用整份從頭看到尾。
- 使用者說「執行 TP-XX」時，指的就是這個資料夾裡對應編號的那份檔案；開始執行前先讀那份檔案，以裡面寫的內容為準。

## 任務包超過五階段時的處理原則

當一個任務包的階段數超過五個，應主動拆成兩個獨立任務包，編號各自遞增（例如 `TP-09`、`TP-10`），讓使用者能分開驗收，不需要等待整包跑完才能看到任何一部分的成果。
