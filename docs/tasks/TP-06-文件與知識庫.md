## 階段 G：工具手冊（`docs/tools/`）

`docs/tools/README.md`：一張表列出工具名、角色、狀態（使用中／已設定未用／未接），依「這件事該找哪個工具」分類（寫程式、部署、資料庫、檔案、通知、文件、自動化），每個工具連到自己那份。

每個工具一份 `docs/tools/<名稱>.md`，固定六節：
1. 這個專案用它做什麼
2. 目前的設定（金鑰只寫放在哪，絕不寫值）
3. 常用操作
4. 踩過的坑（最重要）
5. 限制與風險
6. 未驗證／待確認

要寫的工具：使用中——Supabase、GitHub + Pages、gh CLI、Claude Code、Node/npm、Git、PowerShell；已設定未用——notify.ps1 與 agent_alerts 回報機制；未接但已規劃——LINE Messaging API、Supabase Edge Functions。

必須記錄的實際事故：帳號註冊順序導致登不進去、Site URL 預設 localhost、驗證信 10 分鐘過期、PowerShell 執行原則擋住 npm.ps1、gh PATH 未刷新、gh auth login 需互動、免費帳號 private repo 會關 Pages、建表時選 Run without RLS、照片存 base64 撐爆資料庫。
