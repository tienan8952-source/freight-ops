# 使用者操作手冊

這份是寫給**你自己**看的，不是給 Claude Code 或其他 AI 讀的說明文件（那些在 `docs/tools/` 底下，內容細節不一樣）。這份只講「你打開電腦、要跟這個專案互動時，實際上手指要點哪裡」。

跟 `docs/使用說明.md` 的差別：那份是給貨運行員工（司機、會計）用系統本身的教學；這份是給**你**（維護/開發這個系統的人）用 Claude Code、Supabase、GitHub 的教學。

---

## 一、日常開機三件事

1. **開哪個程式**：開 **Claude Code 桌面版**。不建議自己另外開 PowerShell 視窗手動下指令——Claude Code 會自己呼叫需要的工具（`git`、`gh`、PowerShell 腳本等），你只要用中文打字跟它說要做什麼就好。
2. **怎麼確認接的是對的專案**：Claude Code 開啟後，畫面上應該要能看到目前的工作資料夾是 `C:\Users\User\Documents\freight-ops`（或它明確講出「freight-ops」這個名字）。如果不確定，直接打字問它：「你現在在哪個資料夾、這是什麼專案？」，它會讀 `CLAUDE.md`／`docs/project-brief.md` 回答你。
3. **開始工作前要不要先跑 `/健康檢查`**：不是每次都必須，但**如果你已經好幾天沒開，或不確定上次做到哪**，先打 `/健康檢查`，它會把連線、備份時間、有沒有未處理的通知都列出來給你看，比自己回想安心。

## 二、Claude Code 桌面版

- **怎麼開啟、怎麼切換到 freight-ops 專案**：這一段跟桌面版實際的視窗操作有關，**未驗證**——我沒有實際操作過桌面版介面，無法保證按鈕名稱或畫面配置。建議你自己操作一次記下來，或直接問 Claude Code 本身「怎麼在桌面版切換到別的專案資料夾」，讓它依照當下版本的實際畫面回答你。
- **常用的幾句話怎麼下**：
  - 貼一個任務包：直接把整段任務包文字貼進去，不用加額外說明，它看得懂 `【TP-XX】` 這種格式
  - 問進度：「現在做到哪了？」「TP-07 做完了嗎？」
  - 叫它讀某份文件：「讀一下 `docs/recovery.md`，跟我說有哪四種情境」
  - 叫它執行已存的任務包：「執行 TP-09」（它會去 `docs/tasks/` 找對應編號的檔案）
- **看到什麼代表在跑、看到什麼代表卡住需要你**：
  - 畫面上持續有文字輸出、工具呼叫紀錄在跳動：正常在跑，不用管它
  - 它明確用文字說「需要你手動執行 SQL」或「需要你貼金鑰」，並且／或是你的電腦跳出系統通知（`scripts/notify.ps1` 觸發的）：這才是真的需要你動手的時候
  - 長時間沒有任何新輸出、也沒有跳通知：有可能是在跑很久的步驟（例如大型任務包的 Playwright 截圖驗證），也可能是額度限制在等重置（見 `docs/緊急對照卡.md`「Claude Code 卡住不動」那條），不確定的話直接問它「還在跑嗎？」

## 三、Supabase 後台

- **網址**：<https://supabase.com/dashboard>（登入後選 `freight-ops` 對應的專案，專案參考碼 `ekzqrpgrxicyvaqagdjp`）
- **怎麼登入**：用你申請 Supabase 時的帳號登入，登入方式（Email／GitHub 等）**未驗證**，看你當初怎麼申請的
- **你真的會用到的三個地方**：
  1. **Table Editor**：看資料庫裡各表目前的資料，最直覺的「資料到底有沒有進去」確認方式
  2. **SQL Editor**：任務包印出「請你執行這段 SQL」時，貼上去執行的地方
  3. **Authentication**：管理使用者帳號（例如新人註冊後，這裡也看得到帳號清單，不過核准帳號建議直接在系統內的「帳號管理」頁做，比較不會誤觸其他設定）
- **其他頁面**：不用碰，Claude Code 會處理（Database 的 schema/RLS 設定、Storage 的 bucket 政策、API 設定等都是透過任務包裡的 SQL 或程式碼調整，不需要你在後台手動改）

## 四、GitHub 網頁

- **網址**：<https://github.com/tienan8952-source/freight-ops>
- **怎麼看目前的檔案**：直接在網址上瀏覽，或用 GitHub 網頁上方的搜尋找檔名
- **怎麼看某次任務包做了什麼改動**：點網址上的「`XX commits`」連結（或直接開 <https://github.com/tienan8952-source/freight-ops/commits/main>），每一筆 commit 的標題通常會寫「TP-XX 階段 N：做了什麼」，點進去可以看到實際改了哪些檔案、改了什麼內容（綠色是新增、紅色是刪除）
- **什麼時候需要你自己來這裡**：幾乎不需要。例外情況：
  - 想確認 Claude Code 真的有 push 成功（它通常會自己回報，但你想自己眼見為憑）
  - 想看某次改動的詳細內容，而不只是聽文字回報
  - 需要決定 repo 要不要改成 private、要不要開 PR 流程這類政策性問題（這些 Claude Code 不會自己決定，會留在 `docs/pending-info.md` 等你回答）

## 五、線上系統本身

- **網址**：<https://tienan8952-source.github.io/freight-ops/>
- **怎麼加到瀏覽器書籤**：打開網址後按網址列旁邊的星號圖示
- **手機怎麼加到主畫面**：瀏覽器選單裡找「加到主畫面」或分享按鈕裡的對應選項（iOS Safari 跟 Android Chrome 選單位置略有不同，實際按鈕位置**未驗證**，圖示點一下試試通常找得到）
- **忘記密碼怎麼辦**：目前系統沒有自動找回密碼的功能，要請管理員到「帳號管理」頁協助處理，或到 Supabase 後台 Authentication 頁面手動重設
- **卡住畫面空白怎麼辦**：先試（1）重新整理頁面（2）確認網址打對（3）換一個瀏覽器或無痕視窗試試看是不是快取問題（4）如果還是空白，打開瀏覽器開發者工具的 Console 分頁看有沒有紅字錯誤，把錯誤訊息貼給 Claude Code 讓它幫你查

## 六、`.claude/commands/` 這組指令你也能用

在 Claude Code 裡直接打以下指令（不用等我給你完整任務包）：

| 指令 | 做什麼、什麼時候該用 |
|---|---|
| `/健康檢查` | 檢查 Supabase 連線、各表筆數、備份時間、有沒有未處理的通知、有沒有未提交的變更。**平常想確認系統狀態時用這個。** |
| `/備份` | 手動跑一次備份（匯出所有表到本機 `backups/`）。**想額外備份一次、不想等排程時用。** |
| `/部署` | commit、push、確認網站正常。**改完想確認有沒有正確上線時用。** |
| `/新功能` | 新增一個功能，一次只做一個。**你想加一個新的東西時用這個開頭。** |
| `/修bug` | 修一個 bug，不會順手重構其他東西。**東西壞了、要修正時用。** |
| `/加欄位` | 幫某個模組加一個欄位，會提醒五個要一起改的地方（表單、清單、匯出、匯入、資料字典）。**想在既有模組多加一個欄位時用。** |
| `/加資料表` | 新增一整張表（等於新模組），schema/RLS/前端/權限/選單/資料字典一次做齊。**想加一個全新的模組時用。** |
| `/交接` | 產生「做到哪、卡在哪、下一步」的狀態摘要。**要暫停一陣子、或想留紀錄給之後的自己/別人接手時用。** |
