# 緊急對照卡

情境對指令，一行問題配一行答案，遇到狀況直接找對應那行照做。

**「網站打不開」** → 先看 `docs/incident.md`「網站打不開」那條（確認網址、看 HTTP 狀態碼、查 GitHub Pages 設定），再看 `docs/recovery.md` 情境一/二（換電腦或 Supabase 專案真的沒了才需要）。

**「忘記怎麼跑備份」** → 打開 Claude Code，說「`/備份`」。

**「員工說系統怪怪的」** → 你可以先問她：*是完全打不開，還是能打開但某個功能怪怪的？*、*是所有人都這樣還是只有她？*、*是不是剛好在填某張表單時發生的？* 問完把她的回答轉述給 Claude Code，說「使用者回報系統怪怪的，情況是：（貼上回答）」，讓它幫忙查。

**「Claude Code 卡住不動」** → 先看有沒有文字說「額度限制」「usage limit」「rate limit」：
- 有：這是在等額度重置，不是真的卡住，等一段時間或依它說的時間點再回來就會自動繼續（`CLAUDE.md`「額度與中斷處理」規則就是為了這種情況寫的）
- 沒有這類字眼、也完全沒有任何新輸出很久：直接打字問它「還在跑嗎？」，或看看是不是在跑一個你知道本來就會花比較久的步驟（例如大改版時的 Playwright 截圖驗證）

**「我想加一個功能」** → 直接用中文描述你要的東西給 Claude Code 就好（例如「我想在維修單加一個備註欄位」），不用自己學怎麼寫任務包——它會判斷該用 `/加欄位`、`/新功能` 還是其他方式處理。只有真的很大、很多步驟的需求，才需要寫成完整任務包。
