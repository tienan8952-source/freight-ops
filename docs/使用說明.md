# 貨運行營運系統 使用說明

這份說明是給完全不懂電腦的人看的，照著做就好。

## 一、怎麼打開系統

- 網址：`https://tienan8952-source.github.io/freight-ops/`
- **電腦**：用瀏覽器（Chrome、Edge 都可以）打開網址，打開後按網址列旁邊的星星，就會加到我的最愛，下次點我的最愛就能直接進來。
- **手機**：用手機瀏覽器打開網址，點右上角或右下角的「⋮」或分享的按鈕，選「加到主畫面」，桌面就會出現一個 App 圖示，之後點那個圖示就能開，跟開 App 一樣方便。

## 二、怎麼登入

- 第一次使用要先「註冊」：填姓名、Email、密碼，送出。
- 註冊完不會馬上能用，要等管理員幫你開通帳號、設定你能看哪些模組。開通後重新登入就能用了。
- 已經有帳號的人直接輸入 Email、密碼，按「登入」。
- 忘記密碼目前要請管理員協助，還沒有自動找回密碼的功能。

## 三、每個模組怎麼填

登入後，畫面左邊是選單，中間是資料。基本操作都一樣：

1. 左邊點你要用的模組，例如「出車報班」。
2. 畫面左半邊會出現一張表單，填好資料。
3. 標示紅色星號 `*` 的欄位一定要填。
4. 填完按「存檔」，資料就會出現在右邊的清單裡。
5. 要改資料，去右邊清單找到那一列，點「修改」，改完再按「更新」。
6. 要刪除，點那一列的「刪除」，系統會再確認一次。

常用模組：

- **出車報班**：司機每趟跑完就記一筆，車號、駕駛、客戶、運費都填一下。有連續好幾趟很像的，可以按「複製上一筆」，只要改幾個欄位就好，不用整張重填。
- **車輛維修**：車子進廠保養或修理就記一筆，可以拍照片存單據。
- **零用金**：加油、過路費這類小額支出。
- **客戶對帳**：跟客戶或廠商的應收應付帳款。
- **保險／到期**：保險、驗車、牌照稅這些有到期日的東西，快到期系統會自動提醒。
- **公文合約建檔**：公文、合約、信件這類文件建檔留存。
- **基本資料**：車輛、駕駛、客戶的基本資料，第一次用建議先把「車輛」建好，之後填別的表單車號就會自動跳出來選。

## 四、怎麼拍照上傳

有些模組（維修、零用金、保險、公文）有「照片」欄位：

1. 點「選擇照片」，用手機直接拍照，或從相簿選照片。
2. 也可以點「從檔案庫選擇」，挑之前已經上傳過的照片，不用重拍。
3. 照片存檔前會自動壓縮，不會佔太多空間。

左邊選單有一個「檔案庫」，可以看到系統裡所有上傳過的檔案（不只是照片，PDF、Word、Excel 都可以丟進去），可以用檔名搜尋、依模組或上傳的人篩選。

## 五、怎麼送簽和轉交

如果你的帳號有「我的工作」的權限：

- 在維修單、報帳這類資料的清單裡，每一列會有「送簽」按鈕，點了就能建立一張工作單，指派給某個部門或某個人去處理、審核。
- 左邊點「我的工作」也可以直接「＋ 新增工作單」，不用先有業務資料，自己打標題說明也可以送出。
- 工作單送出後，對方會收到通知。
- 收到工作單的人可以「轉交」給別人或別的部門（要填轉交說明），也可以「處理完成」，如果這張工作單需要審核，還會有「核准」「退回」（退回要寫原因）。
- 每一張工作單下面都看得到完整的處理紀錄：誰在什麼時候做了什麼、說了什麼。

## 六、怎麼看待辦

- 左邊「我的工作」旁邊如果有紅色數字，代表你有幾件工作單還沒處理。
- 點「我的工作」，上面有三個分頁：「待我處理」「我送出的」「已完成」。
- 右上角有個鈴鐺 🔔，點開會看到通知清單，點通知會直接跳到那張工作單，並且標記已讀。
- 總覽頁最上面也會顯示「待我處理幾件、其中逾期幾件」。

## 七、怎麼匯出給會計

- 每個模組的清單上面都有「匯出 Excel」，會下載一個 CSV 檔，Excel 可以直接打開。
- 想要一次匯出全部資料，管理員可以到「系統維護」按「匯出全部 Excel」，會下載一個壓縮檔，裡面每個模組一個 CSV。
- 「薪資計算」頁可以選月份，匯出那個月的薪資明細給會計對帳。

## 八、原本 Excel 的資料怎麼搬進來

這個功能要請管理員操作：

1. 左邊點「匯入資料」（只有管理員看得到）。
2. 選要匯入哪個模組，上傳 Excel 或 CSV 檔案。
3. 系統會列出 Excel 的欄位，一個一個對應到系統的欄位。
4. 按「檢查資料」，如果有問題的列會標紅，可以選擇跳過或取消。
5. 確認沒問題就按「開始匯入」，會顯示匯入進度，完成後會告訴你成功幾筆、跳過幾筆。

## 九、遇到問題怎麼辦

- **畫面說「帳號等待管理員核准」**：表示你已經註冊成功，等管理員開通就好，不用重複註冊。
- **看不到某個模組**：代表你的帳號還沒有那個模組的權限，請管理員到「帳號管理」幫你打開。
- **存檔失敗**：通常是紅色星號的欄位沒填，或是網路不穩，檢查一下再試一次。
- **照片上傳不了**：檢查一下網路，或換一張小一點的照片再試。
- **完全打不開系統**：確認網址有沒有打對，或問問其他同事是不是也打不開。
- 其他問題，直接找系統管理員反應就好。
